# TaskFlow — Student Productivity Dashboard 🌈

TaskFlow is a colourful, responsive student productivity dashboard designed to help students manage their academic tasks, personal activities, and projects in one place. Built using HTML, CSS, and JavaScript, it provides a simple and organised way to plan tasks, track deadlines, and monitor progress.

## 🎯 Features

- **Task Management:** Add, complete, and delete tasks.
- **Task Categories:** Organise tasks into College, Personal, Projects, and Other.
- **Priority Levels:** Set priorities to manage important tasks.
- **Deadline Tracking:** Add due dates to stay organised.
- **Search & Filtering:** Find tasks and filter them by status or category.
- **Dashboard Statistics:** View task progress and completion statistics.
- **Light & Dark Mode:** Switch between themes.
- **Local Storage:** Save tasks and theme preferences in your browser.
- **Responsive Design:** Designed to work across desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/taskflow.git
```

### 2. Open the project

Navigate to the project folder and open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient development experience.

## 📌 How to Use

1. Open the TaskFlow dashboard.
2. Add a task with its category, priority, and deadline.
3. Search for tasks or filter them by category and status.
4. Mark tasks as completed when finished.
5. Track your progress using the dashboard statistics.
6. Switch between light and dark mode according to your preference.

## 🎓 Project Purpose

TaskFlow was created to explore front-end web development while building a practical tool for everyday student life. It combines task organisation, a colourful interface, and useful productivity features in a single dashboard.
